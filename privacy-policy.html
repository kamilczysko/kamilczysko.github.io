Privacy Policy for Practice Buddy Extension

Last updated: August 11, 2026

Practice Buddy Extension ("Practice Buddy", "we", "our", or "the extension") is a Chrome extension designed to help musicians practice songs and musical passages on YouTube.

1. Information We Collect

Practice Buddy does not collect or transmit personal information to our servers.

The extension may store the following information locally on the user's device using Chrome's storage functionality:

  • Practice markers and timestamps created by the user
  • Saved practice presets
  • Notes entered by the user
  • Extension preferences and settings

This information is stored locally through the Chrome extension storage API and is not transmitted to us.

2. YouTube Pages

Practice Buddy operates on YouTube pages in order to provide its practice features, including markers, looping, playback speed controls, and other practice-related functionality.

The extension may access information available on the current YouTube video page that is necessary to provide these features, such as the current video and playback state.

Practice Buddy does not collect or store the user's YouTube account information, passwords, authentication credentials, or personal communications.

3. How We Use Information

Information stored by Practice Buddy is used solely to provide and maintain the extension's functionality.

For example, saved markers and presets allow users to return to previously configured practice sections.

We do not use user data for advertising, profiling, or tracking.

4. Data Sharing

Practice Buddy does not sell, rent, or share user data with third parties.

The extension does not transmit the locally stored practice data to external servers.

5. Data Storage and Retention

Practice data remains in the Chrome extension's local storage on the user's device until the user removes it or the extension's stored data is cleared.

We do not maintain a separate copy of this information on our servers.

6. Security

Because Practice Buddy does not transmit the stored practice data to our servers, there is no server-side collection or processing of this data by us.

Users should keep their Chrome installation and operating system up to date to maintain the security of their device.

7. Third-Party Services

Practice Buddy operates on YouTube and does not use third-party analytics, advertising, tracking, or data-broker services.

YouTube is operated by Google and is subject to Google's own privacy practices and policies.

8. Chrome Web Store User Data Policy

Practice Buddy uses information received through Chrome extension APIs only to provide its disclosed functionality.

The use of information received through Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

9. Changes to This Privacy Policy

We may update this Privacy Policy when the extension's data practices or functionality change.

If material changes are made to how user data is handled, the updated Privacy Policy will be published at this URL.
